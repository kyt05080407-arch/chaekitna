# 프록시 배포 안내 (Google Apps Script)

구글 계정 하나로 10분 정도면 끝나요. 정보나루 인증키는 이 스크립트의 "스크립트 속성"에만 저장되고, 앱 코드나 GitHub에는 올라가지 않아요.

## 준비물

- 구글 계정
- 도서관 정보나루 인증키 (승인이 끝난 것)

## 1. 프로젝트 만들기

1. [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만들어요.
2. 왼쪽 위 제목을 `책있나 프록시`로 바꿔요.
3. 기본으로 들어 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](Code.gs)를 통째로 붙여 넣어요.
4. 왼쪽 ⚙ **프로젝트 설정**에서 "편집기에서 'appsscript.json' 매니페스트 파일 표시"를 켜요.
5. 편집기로 돌아와 `appsscript.json` 내용을 이 폴더의 [`appsscript.json`](appsscript.json)으로 바꾸고 저장(Ctrl+S)해요.

## 2. 인증키 넣기

⚙ **프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**

| 속성 | 값 | 꼭 필요? |
|---|---|---|
| `D4L_AUTH_KEY` | 정보나루 인증키 | 필수 |
| `DAILY_LIMIT` | 하루 최대 호출 수 (안 넣으면 450) | 선택 |
| `ADMIN_TOKEN` | 남이 맞힐 수 없는 긴 임의 문자열 | v1.1 알림 기능 때 |

## 3. 시험 실행

1. 편집기 위쪽 함수 목록에서 `testSetup`을 고르고 **실행**을 눌러요.
2. 처음에는 권한 확인 창이 떠요. 계정을 고르고, "Google에서 확인하지 않은 앱" 안내가 나오면 **고급 → 책있나 프록시(으)로 이동**을 눌러 허용해요. 내가 직접 만든 스크립트라서 나오는 안내예요.
3. 실행 로그에 `인증키 동작 확인`이 보이면 성공이에요. 응답 코드가 보이면 인증키 승인 여부와 값을 다시 확인해 주세요.
4. 함수 목록에서 `installTriggers`를 골라 한 번 더 실행해요. 매일 새벽 4시에 31일 지난 기록을 지우는 트리거가 만들어져요.

## 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. **유형 선택**(⚙) → **웹 앱**
3. 설명은 `v1`, **다음 사용자 인증 정보로 실행**은 `나`, **액세스 권한이 있는 사용자**는 `모든 사용자`로 해요.
4. **배포**를 누르고 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사해요.
5. 브라우저 주소창에 그 URL 뒤에 `?op=health`를 붙여 열어 봐요. `"ok":true`와 `"keyConfigured":true`가 보이면 준비 끝이에요.

"모든 사용자"로 여는 이유: 앱을 쓰는 사람이 구글 로그인 없이 조회할 수 있어야 해서예요. 대신 이 프록시는 정해진 조회(검색·상세·소장·대출 가능 여부)만 받고, 하루 호출 수를 스스로 제한해요.

## 5. 앱에 연결

`js/config.js`의 `proxyUrl`에 복사한 URL을 넣고 커밋하면 예시 데이터 모드가 꺼지고 실제 데이터로 바뀌어요.

## 코드를 고친 뒤 다시 배포하기 (주소 유지)

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**

"새 배포"를 다시 누르면 주소가 바뀌어서 앱의 `proxyUrl`도 바꿔야 해요.

## 한도

| 항목 | 한도 | 이 프록시에서 |
|---|---|---|
| 정보나루 하루 호출 | 공식 활용방법 페이지에서는 숫자를 확인하지 못했어요 | 기본 450회로 스스로 제한 (`DAILY_LIMIT`) |
| Apps Script 외부 호출(UrlFetch) | 무료 계정 하루 20,000회 | 정보나루 호출 수와 같아서 여유 |
| Apps Script 속성 읽기·쓰기 | 무료 계정 하루 50,000회 | 조회 1번에 약 6회 → 하루 약 8,000번 조회까지 |
| Apps Script 속성 저장 공간 | 500KB | 날짜별 기록은 31일 뒤 자동 삭제 |

- 인증키 발급 안내에 하루 한도가 적혀 있으면 `DAILY_LIMIT`를 그보다 조금 낮게 맞춰 주세요.
- 같은 조회는 6시간 동안 캐시에서 돌려줘서 정보나루를 다시 부르지 않아요. 앱도 폰에 결과를 따로 저장해요(대출 정보는 다음 날 아침 9시까지).
- 한도를 다 쓰면 앱에 "오늘 조회 한도를 다 썼어요. 도서관 홈페이지에서 확인해 주세요"가 나오고, 이미 캐시된 도서관 결과는 계속 보여요.

출처: [Apps Script 할당량](https://developers.google.com/apps-script/guides/services/quotas), [Apps Script 웹 앱](https://developers.google.com/apps-script/guides/web), [정보나루 Open API 활용방법](https://www.data4library.kr/apiUtilization)

## 요청 형식

모든 요청은 `GET {프록시 URL}?op=…` 형태예요. 응답은 JSON이고, 문제가 있으면 `{ "error": "코드", "message": "설명" }`을 돌려줘요.

| op | 매개변수 | 하는 일 |
|---|---|---|
| `health` | 없음 | 상태, 오늘·어제 호출 수, 기능별 사용 횟수 |
| `search` | `q`, `page`, `sort` (`loan` / `pubYear` / `title`) | 책 검색. `q`가 13자리 숫자면 ISBN으로 찾음 |
| `detail` | `isbn` | 책 한 권 정보 |
| `holdings` | `isbn`, `region` (시·도 코드) | 그 지역에서 이 책을 가진 도서관 |
| `exist` | `isbn`, `libs` (쉼표로 구분, 최대 5곳) | 도서관별 소장·대출 가능 여부 |
| `export` | `token` | (v1.1) 알림 구독 목록. `ADMIN_TOKEN`과 같아야 함 |

| error | 뜻 |
|---|---|
| `bad_request` | 매개변수가 잘못됨 |
| `budget` | 오늘 호출 한도를 다 씀 |
| `not_configured` | `D4L_AUTH_KEY`가 없음 |
| `upstream` | 정보나루가 오류를 돌려주거나 응답하지 않음 |
| `forbidden` | `export`의 token이 틀림 |

## 저장하는 것

- 날짜별 호출 수(`usage:날짜`)와 기능별 사용 횟수(`stats:날짜`). 누가 요청했는지는 남기지 않아요.
- (v1.1) 알림을 켠 사람의 푸시 주소와 키, 관심 도서 ISBN, 도서관 코드. 이름·연락처는 없고, 90일 동안 갱신이 없으면 지워요.
